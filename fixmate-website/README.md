# FixMate – Pure HTML, CSS & JavaScript Edition

**FixMate – The Right Professional. Right When You Need Them.**

This package contains a 100% standalone website built using only **HTML5**, **CSS3**, and **Vanilla JavaScript** (zero frameworks, zero build tools, zero external runtime dependencies).

## Folder Structure

- `index.html` — Complete semantic HTML5 application views and modals
- `css/style.css` — Responsive design system, animations, and dashboard styles
- `js/app.js` — Complete marketplace logic, filters, comparison, booking engine, Smart Service Matcher, Customer/Professional/Admin dashboards, and `localStorage` persistence
- `images/` — Local bundled photography assets

## How to Run

Simply unzip this folder and double-click `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari) or serve it with any static server.
